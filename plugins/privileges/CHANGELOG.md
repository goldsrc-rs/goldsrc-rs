# Changelog - goldsrc:privileges

## [0.17.0] - 2026-10-02

### Added

- Independent feature crate replacing legacy `vip_core` prototype.
- Multilingual localization support via `resources/lang/privileges.toml`.
- Round tracking and per-round weapon claim protection logic.
- Passive ECS health regeneration system with live toggle.
- Interactive VIP menu with round restriction badges.
- Type-safe `CvarFlags` and `range` clamping in `PrivilegesConfig`.
